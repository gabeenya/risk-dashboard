  • 상단 헤더 — 시스템 제목, 현재 페이지 표시, 동기화 상태, 새로고침(↻) 버튼

1. 가입 신청

  1. 로그인 화면 하단의 "계정이 없으신가요? 가입 신청" 을 클릭합니다.
  2. 아래 항목을 입력합니다.
    • 이름 — 실제 이름
    • 아이디 — 영문/숫자 조합(. - _ 사용 가능)
    • 비밀번호 — 4자 이상
    • 희망 접근 브랜드 — 조회하려는 브랜드를 1개 이상 선택(모두 선택/모두 해제 제공)
  3. 가입 신청 버튼을 누릅니다.
  4. "가입 신청 완료 — 관리자 승인 후 로그인 가능합니다." 안내가 뜨면 접수 완료입니다.
⚠️ 신청 직후에는 로그인되지 않습니다. 관리자가 승인해야 로그인할 수 있고, 승인 단계에서 접근 브랜드·영역 권한이 최종 확정됩니다. 승인 전 로그인 시 "관리자 승인 대기 중인 계정입니다." 가 표시됩니다.

2. 로그인 · 세션 · 비밀번호

로그인

  • 아이디·비밀번호를 입력하고 로그인(또는 비밀번호 칸에서 Enter)을 누릅니다.
  • 로그인하면 자동으로 대시보드로 이동합니다.

세션 유지 / 자동 로그아웃

  • 브라우저를 새로고침해도 로그인이 유지됩니다.
  • 보안을 위해 로그인 후 3시간이 지나면 자동 로그아웃됩니다.
  • 만료 5분 전 경고 팝업이 뜹니다 — 세션 연장(3시간) 또는 지금 로그아웃.

비밀번호 변경 / 로그아웃

  • 사이드바 하단 🔑 비밀번호 → 현재 비밀번호 확인 후 새 비밀번호(4자 이상)로 변경.
  • 사이드바 하단 ⎋ 로그아웃 → 로그인 화면으로 복귀.

3. 대시보드 — 현황 한눈에 보기

로그인 후 가장 먼저 보이는 화면입니다.

3-1. 기준 월 · 필터

  • 기준 월 — 조회할 월 선택, 당월 버튼으로 이번 달 복귀.
  • 영역 필터 — 11개 영역 중 하나 또는 전체 영역.
  • 브랜드 필터 — 본인 권한 내 브랜드 또는 전체 브랜드.
  • 사이드바 리스크 영역 현황의 영역 이름을 눌러도 필터가 걸립니다.

3-2. 상단 알림 바

당월 위반이 전월 대비 임계치 이상 급증한 영역이 있으면 화면 상단에 빨간 알림 바가 표시됩니다(임계치는 관리자가 설정 — 7장).

3-3. KPI 카드 4개

  • 누적 위반/모니터링 — 연 누적 집계
  • 당월 위반/모니터링 — 선택한 기준 월 집계
  • 처리 완료율 — 전체 대비 완료 비율
  • 현재 조치중 건수 — 위반(처리중) 상태 건수

3-4. 차트

  • 월별 모니터링/위반 건수 추이(라인) — 월별 흐름
  • 위반 유형별 분포(도넛) — 영역·상세유형 비중
  • 브랜드별 현황(바) — 브랜드별 모니터링·위반 비교
📌 영업비밀 환산 안내 — 영업비밀의 모니터링 건수는 그래프에서 10:1로 환산되어 표시됩니다(위반 건수는 1:1 그대로). 예) 실제 모니터링 1,540건·위반 3건 → 그래프에는 154건·3건으로 반영.

3-5. 최근 모니터링 현황 (표)

  • 날짜·유형·상세·브랜드·상태·비고를 최신순으로 표시.
  • 상태별 필터 버튼: 전체 / 모니터링 / 위반(처리중) / 완료.
  • 표 아래 페이지 번호로 넘겨봅니다.

3-6. 브랜드/영역별 위험도 히트맵

  • 위반이 많은 브랜드와 상위 영역을 색 농도로 표시.
  • 카드/칩을 클릭하면 오른쪽 드릴다운 패널이 열려 해당 조합의 상세 기록(날짜·상세유형·브랜드·건수·상태·작성자·비고)을 보여줍니다. ✕ 로 닫습니다.

4. 데이터 입력 관리자 이상

사이드바 데이터 입력 탭에서 진행합니다. 맨 위 리스크 영역을 먼저 선택하면 이후 입력이 그 영역 기준으로 동작합니다.

4-1. 엑셀 일괄 업로드 (여러 건 한 번에)

  1. 📥 양식 다운로드 로 표준 엑셀 양식을 받습니다.
  2. 양식의 데이터 시트만 채웁니다 — 첫 행(헤더)은 그대로 두고 둘째 행부터 입력. 같은 양식으로 여러 영역을 한 번에 올릴 수 있습니다.
  3. 📂 엑셀 파일 선택(.xlsx) 으로 파일 선택.
  4. 미리보기에서 ✓ 유효·✕ 오류·전체 행 수를 확인.
  5. ✓ 유효 건 업로드 → 유효한 행만 등록(오류 행은 사유 표시 / 취소 가능).

4-2. 안전 점검표 업로드 (영역이 '안전'일 때만 표시)

  • 안전 점검표 파일의 첫 번째 시트만 읽습니다.
  • 매장(행)별 점검 항목을 자동 전개해 등록 — 값이 0이 아니면 → 위반(처리중), 0이면 → 모니터링, 빈 칸은 제외.
  • 영역은 안전 고정, 매장명은 비고로 저장.
⚠️ 문서보안(DRM)이 걸린 파일은 읽을 수 없습니다 — 보안 해제(반출)된 사본으로 업로드하세요.

4-3. 신규 입력 (한 건씩)

다음을 채우고 입력하기(초기화로 비움): 날짜 / 위반 유형(선택 영역 자동) / 상세 위반 유형 / 브랜드 / 건수 / 상태 / 비고(선택).

4-4. 데이터 목록 (조회·수정·삭제)

  • 상세유형·브랜드·건수·상태·비고는 목록에서 바로 클릭해 수정.
  • 상단 필터: 상세유형 / 브랜드 / 상태(필터 초기화 제공), 현재 건수 표시.
  • 여러 건 선택(맨 앞 체크박스): 선택 상태 변경 / 선택 삭제를 한 번에.

5. AI 리스크 분석

사이드바 AI 분석 탭에서 필요한 부분만 골라 분석 리포트를 받습니다.

  1. 1. 분석 대상 브랜드 선택 — 분석할 브랜드 선택. 선택하지 않으면 전체 브랜드가 대상.
  2. 2. 분석 항목 선택(복수 가능) — 위험도 식별 / 트렌드 분석 / 완료율 / 권고사항 / 액션 플랜 / 브랜드별 비교(위험도·트렌드는 기본 선택).
  3. 추가 컨텍스트(선택) — 분석 관점을 한 줄로. 예) "브랜드장 입장에서 우리 브랜드 리스크 관리 수준 분석".
  4. 출력 스타일 — 📝 노션 / 📰 신문 / 💻 터미널.
  5. ✦ AI 분석 시작 클릭 — 선택 항목 수에 따라 약 5~30초 소요, 결과는 하단에 표시.
💡 한 번에 너무 많은 항목보다 궁금한 항목만 골라 짧게 돌리면 더 빠르고 또렷한 결과를 얻습니다.

6. 보고서 생성 (PPT) 관리자 이상

사이드바 보고서 생성 → 모달에서 진행합니다.

  1. 기준 월 선택(비워두면 지난 달 데이터로 생성).
  2. 보고서 생성 클릭 → PPTX 파일이 자동 생성·다운로드됩니다.

생성 슬라이드: ① 표지 ② 법인 전체 개요(KPI 4 + 월별 추이) ③ 브랜드별 종합(연누적·당월 × 영역별 전체/위반 + 합계) ④ 영역별 상세(표 + 도넛 + 핵심 지표).

7. 관리자 페이지 최상위 관리자 전용

7-1. 가입 신청 대기 (승인/거절)

  • 신청이 있으면 대기 목록 표시(없으면 숨김).
  • 승인 — 부여할 접근 브랜드·확인 가능 영역을 선택해 확정(신청 시 고른 브랜드가 미리 체크됨) → 즉시 로그인 가능.
  • 거절 — 신청 삭제.

7-2. 새 계정 직접 추가

  1. 이름·아이디·임시 비밀번호(4자 이상) 입력.
  2. 권한 선택 — 브랜드장(조회 전용)(아래에서 접근 브랜드·영역 지정) 또는 관리자(입력/보고서 포함, 전체 브랜드).
  3. 계정 추가 → 생성 정보를 복사해 팀원에게 전달.

7-3. 가입된 사용자 관리

사용자 목록에서 권한·접근 브랜드·접근 영역·이름을 행에서 직접 수정합니다.

7-4. 영역별 알림 임계치

  • 영역마다 전월 대비 +건수 또는 +% 임계치 설정.
  • 당월 위반이 임계치 이상 증가하면 대시보드 상단에 알림 바 표시.
  • 임계치 저장 / 기본값 복원 제공.

8. 자주 묻는 질문 (FAQ)

Q. 가입했는데 로그인이 안 됩니다.
→ 관리자 승인 전입니다. 승인되면 바로 로그인됩니다.

Q. 데이터 입력 / 보고서 생성 탭이 동작하지 않아요.
→ 해당 기능은 관리자 이상 권한이 필요합니다. 권한 변경은 관리자에게 요청하세요.

Q. 일부 브랜드/영역이 화면에 안 보여요.
→ 브랜드장은 승인된 브랜드·영역만 보입니다. 추가 권한은 관리자에게 요청하세요.

Q. 갑자기 로그아웃되었습니다.
→ 보안상 로그인 후 3시간이 지나면 자동 로그아웃됩니다. 다시 로그인하세요.

Q. 영업비밀 모니터링 숫자가 실제보다 적게 보입니다.
→ 그래프에서 모니터링 건수만 10:1로 환산해 표시한 것입니다. 위반 건수는 실제 값입니다.

Q. 안전 점검표 엑셀이 안 올라가요.
→ 문서보안(DRM)이 걸린 파일은 읽지 못합니다. 보안 해제된 사본으로 올려주세요.

Q. 최신 데이터가 안 보여요.
→ 상단 헤더의 ↻ 새로고침 을 눌러 다시 불러오세요.

문의나 권한 요청은 시스템 관리자에게 연락해 주세요.
