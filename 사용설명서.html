📌 안전도 예외 — 위반율이 아니라 "산업재해 발생" 건수만의 월평균 매장당 발생 건수(조치 완료 여부와 무관하게 발생 자체를 카운트)를 등급 기준에 대입합니다. 이 비율만으로는 F를 매기지 않고, 중대재해 발생이 1건이라도 있으면(그 외 등급 산정과 무관하게) 즉시 F가 최우선 적용됩니다.
📌 컴플라이언스 6개 영역(불법파견·표시광고·가맹·IP·노무·영업비밀)은 위반율이 아니라 월평균 매장당 위반+완료 건수(연 누적 위반+완료 건수 ÷ 브랜드 매장수 ÷ 경과개월수)를 등급 기준에 대입합니다. 이 비율만으로는 F를 매기지 않고 최저 D까지만 내려가며, 외부노출이 1건이라도 있을 때만 F로 최우선 적용됩니다. 영역마다 실제 발생 빈도 차이가 커서(예: 불법파견은 전사 반년 실적발이 한 자릿수 수준, 영업비밀은 훨씬 활발) 위 표의 구간을 영역별로 다르게 잡았습니다. 불법파견·가맹·IP는 전사 실적발 자체가 반년간 한 자릿수~10여 건 수준이라 A 기준을 "정확히 0건"으로 엄격하게 잡았습니다 — 무결점 브랜드만 A이고, 1건이라도 발생하면 최소 B로 내려갑니다.

점수 산정 방법

  1. 등급별 점수: A=10점 · B=8점 · C=5점 · D=3점 · F=0점
  2. 브랜드별 종합점수 = 평가 대상 9개 영역 등급 점수의 평균
  3. 종합등급: 평균 9~10점→A, 7~8점→B, 4~6점→C, 1~3점→D, 0점→F
  4. 100점 환산 점수 = 평균점수 × 10 (표에 표시되는 값)

  2. 양식의 데이터 시트만 채움(첫 행은 헤더, 둘째 행부터 입력) — 같은 양식으로 여러 영역 동시 업로드 가능
  3. 📂 엑셀 파일 선택(.xlsx)
  4. 미리보기에서 ✓ 유효 / ✕ 오류 / 전체 행 수 확인
  5. ✓ 유효 건만 업로드(오류 행은 사유 표시, 취소 가능)

4-2. 신규 입력 (한 건씩)

날짜 / 위반 유형(선택 영역 자동) / 상세 위반 유형 / 브랜드 / 매장명(선택) / 상태 / 건수 를 채우고 입력하기(초기화로 비움).

매장명 드롭다운은 브랜드 선택 시 해당 브랜드 소속 매장 목록으로 자동 갱신됩니다. 매장 목록이 없는 브랜드(상권·본부·광주ck·주안ck·기흥ck·CX팀)는 매장명 선택 없이 비워둘 수 있습니다.

4-3. 영역별 특이사항 입력

날짜·브랜드(선택)·주요이슈·이슈상세·조치완료 사항을 입력해 등록. 목록에서 바로 수정·저장·삭제 가능하며, 대시보드 조치사항판의 "영역별 특이사항"에도 함께 반영됩니다.

4-4. 데이터 목록 (조회·수정·삭제)

  • 상세유형·브랜드·매장명·건수·상태·비고는 목록에서 바로 클릭해 수정. 매장명은 해당 행의 브랜드에 등록된 매장 목록으로 표시.
  • 상단 필터: 상세유형 / 브랜드 / 상태(필터 초기화 제공), 현재 건수 표시.
  • 여러 건 선택(체크박스): 선택 상태 변경 / 선택 삭제.

7. 관리자 페이지 최상위 관리자 전용

7-1. 가입 신청 대기 (승인/거절)

  • 신청이 있으면 대기 목록 표시(없으면 숨김).
  • 승인 클릭 → 팝업에서 접근 브랜드·확인 가능 영역을 선택(신청 시 고른 브랜드 미리 체크)해 확정 → 즉시 로그인 가능.
  • 거절 → 신청 삭제.

7-2. 새 계정 직접 추가

  1. 이름 · 아이디 · 임시 비밀번호(4자 이상) 입력
  2. 권한 선택 — 브랜드장(조회 전용)(접근 브랜드·영역 지정) 또는 관리자(입력/보고서 포함, 전체 브랜드)
  3. 계정 추가 → 생성 정보를 복사해 전달

7-3. 가입된 사용자 관리

항목내용
이름✎ 클릭해 수정
권한드롭다운으로 브랜드장/관리자 전환
접근 브랜드 · 접근 영역✎ 클릭해 팝업에서 수정(관리자 권한은 자동으로 "전체")
삭제관리자(admin) 계정을 제외한 사용자를 목록에서 바로 삭제(✕) 가능

7-4. 영역별 알림 임계값

  • 영역마다 당월 위반 +건수 또는 +% 임계값 설정.
  • 당월 위반이 임계값을 초과하면 대시보드 상단에 알림 바 표시(전월 대비 증가분 기준).
  • 임계값 저장 / 기본값 복원 제공.

8. 자주 묻는 질문 (FAQ)

Q. 가입했는데 로그인이 안 됩니다.
→ 관리자 승인 전입니다. 승인되면 바로 로그인됩니다.

Q. 데이터 입력 / 보고서 생성 탭이 동작하지 않아요.
→ 해당 기능은 관리자 이상 권한이 필요합니다. 권한 변경은 관리자에게 요청하세요.

Q. 일부 브랜드/영역이 화면에 안 보여요.
→ 브랜드장은 승인된 브랜드·영역만 보입니다. 추가 권한은 관리자에게 요청하세요.

Q. 갑자기 로그아웃되었습니다.
→ 보안상 로그인 후 3시간이 지나면 자동 로그아웃됩니다. 다시 로그인하세요.

Q. 영업비밀 모니터링 숫자가 실제보다 적게 보입니다.
→ 그래프에서 모니터링 건수만 10:1로 환산해 표시한 것입니다. 위반 건수는 실제 값입니다.

Q. 리스크 노출/측정판과 조치사항이 왜 어떤 화면에서는 나란히, 어떤 화면에서는 따로 보이나요?
→ 분류·영역을 전체로 둔 완전 전체 화면에서만 두 개의 독립 카드로 분리됩니다. 분류나 영역을 좁히면 하나의 카드로 합쳐져 나란히 표시됩니다.

Q. 최신 데이터가 안 보여요.
→ 상단 헤더의 ↻ 새로고침 을 눌러 다시 불러오세요.
