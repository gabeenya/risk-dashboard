users.pw 해시 계산기

Supabase users 테이블의 pw 컬럼에 넣을 값을 만들어줍니다. 계산은 이 페이지 안에서만 일어나며, 네트워크로 전송되지 않습니다.

pw 컬럼에 넣을 값 (pbkdf2 해시)
— 비밀번호를 입력하고 버튼을 누르세요
PBKDF2-SHA256(100,000회, salt 16바이트) 해시입니다 — supabase/functions/auth-login과 assets/js/utils.js의 strongHash()와 동일한 형식(pbkdf2:salt:hash)이라 그대로 users.pw에 넣으면 로그인됩니다. 최초 admin 계정을 콘솔에서 수동 시드할 때 사용하세요.
