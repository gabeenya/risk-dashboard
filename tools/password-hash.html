Supabase users 테이블의 pw 컬럼에 넣을 값을 만들어줍니다. 계산은 이 페이지 안에서만 일어나며, 네트워크로 전송되지 않습니다.

pw 컬럼에 넣을 값 (djb2 해시)
— 비밀번호를 입력하고 버튼을 누르세요
이 해시는 안전한 비밀번호 저장 방식이 아닙니다. 빠르게 무차별 대입(brute force)이 가능한 형식이라, 운영 보안 강화 로드맵의 중기 단계에서 Supabase Auth 또는 bcrypt로 교체될 예정입니다. 지금 단계의 변경은 "기본 비밀번호 admin1234를 강력한 값으로 바꿔두기" 용도입니다.
